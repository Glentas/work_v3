# Belstat Crime Dataset Web App

Web приложение для работы с официальной статистикой правонарушений Белстата. Состоит из FastAPI бэкенда и React/Next.js фронтенда с интерактивными графиками и поиском.

## Быстрый старт

Запустить сразу бэкенд и фронтенд:

```bash
python run_web.py
```

### Доступные сервисы:
- **Фронтенд (Веб-интерфейс):** `http://localhost:3000`
- **FastAPI Бэкенд API:** `http://localhost:8000`
- **Swagger документация API:** `http://localhost:8000/docs`
