# Лабораторная работа 8 — Система синтеза речи

**Вариант 7:** немецкий язык · предметная область «Сочинения по литературе».

Небольшое Flask-приложение (Python, зависимости — **uv**) с веб-интерфейсом.
Поддерживаются **два движка синтеза**:

| Движок | Как работает | Когда использовать |
| --- | --- | --- |
| **Браузер** (Web Speech API, `speechSynthesis`) | голоса операционной системы, синтез в браузере, подсветка предложений | Chrome / Edge (Windows) |
| **Сервер** (`espeak-ng`) | Flask запускает `espeak-ng`, отдаёт WAV, клиент играет через `<audio>` | Firefox / **LibreWolf** / любой Linux |

## Возможности

**Базовые (по требованиям работы):**
- ввод текста вручную, **вставка из буфера обмена**;
- **воспроизведение** сигнала (пауза / продолжить / стоп);
- **настройки голоса**: выбор диктора, темп, высота тона, громкость;
- **поддержка указателя мыши на html-странице**: выделите фрагмент в «читалке» —
  появится кнопка «🔊 Озвучить выделенное»;
- готовые примеры текстов предметной области (немецкие сочинения по литературе).

**Расширенные (сверх минимума):**
- **два движка синтеза** с авто-выбором (см. ниже);
- **подсветка текущего предложения** по ходу синтеза (браузерный движок);
- **загрузка и сохранение `.txt`**, drag-and-drop;
- **сохранение настроек** (движок, голос, темп, тон, громкость, тема) в `localStorage`;
- **статистика текста**: символы, слова, оценочное время чтения;
- **пресеты темпа**, **горячие клавиши** (Ctrl+Enter — воспроизвести, Esc — стоп);
- **светлая/тёмная тема**.

## Запуск (uv)
```bash
cd lab8-synthesis
uv sync            # создаст .venv и установит Flask
uv run app.py      # → http://127.0.0.1:5000
```

## Если нет звука в Firefox / LibreWolf (Linux)

Браузерный `speechSynthesis` в Firefox/LibreWolf опирается на системный
**speech-dispatcher**, которому нужен **движок синтеза**. Сам по себе пакет
`speech-dispatcher` голоса не содержит — поэтому и тишина.

**Рекомендуемый путь — серверный движок (работает всегда):**
```bash
sudo pacman -S espeak-ng      # Arch: движок синтеза
# перезапустите приложение:  uv run app.py
```
Откройте страницу: если немецких голосов в браузере нет, приложение **само
переключится на серверный движок**. Либо выберите его вручную в блоке
«Движок синтеза» → **Сервер (espeak-ng)**. Проверить движок в терминале:
```bash
espeak-ng -v de -w /tmp/test.wav "Guten Tag" && mpv /tmp/test.wav
```

**Альтернатива — починить браузерный движок (speech-dispatcher):**
```bash
sudo pacman -S espeak-ng
spd-conf -uc                  # создать пользовательский конфиг, выбрать espeak-ng
spd-say "Hallo Welt"          # если заговорило — диспетчер настроен
```
Затем полностью перезапустите LibreWolf. Учтите: в LibreWolf Web Speech API
может оставаться недоступным из-за настроек приватности — тогда используйте
серверный движок.

## Как это работает
1. `app.py` отдаёт страницу `/`, примеры `/api/samples`, список голосов сервера
   `/api/server-voices` и синтезирует WAV в `/api/tts` (POST: `text`, `voice`, `rate`, `pitch`).
2. `app.js` при старте запрашивает доступность `espeak-ng` и голоса браузера;
   если немецких голосов в браузере нет и серверный движок доступен — выбирает его.
3. **Браузерный движок:** создаётся `SpeechSynthesisUtterance`; событие `onboundary`
   подсвечивает текущее предложение.
4. **Серверный движок:** текст уходит в `/api/tts`, `espeak-ng` пишет WAV, клиент
   играет его через `<audio>` (громкость — ползунком, темп/тон — пересинтезом).
5. Выделенный мышью фрагмент озвучивается отдельной кнопкой в любом движке.

### Параметры espeak-ng (серверный движок)
- `-v de|de+f1..f4|de+m1..m7|de+whisper|de+croak` — голос/вариант;
- `-s 80..400` — темп (слов/мин, = `175 × rate`);
- `-p 0..99` — высота тона (= `50 × pitch`);
- `-a 100` — амплитуда (громкость регулируется на клиенте);
- `-w out.wav -f in.txt` — запись WAV из UTF-8 файла.
