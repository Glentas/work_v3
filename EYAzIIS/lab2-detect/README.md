# Автоматическое распознавание языка текста

Учебная система распознавания языка текстовых документов
(лабораторная работа 2, **вариант 7**): сравнение поисковых образов документа
и языка тремя методами — N-грамм, алфавитным и нейросетевым.

| Параметр варианта | Значение |
|---|---|
| Языки текста | французский, английский |
| Формат документа | HTML |
| Реализуемые методы | N-грамм, алфавитный, нейросетевой (fastText) |
| Тренировочный набор | по 100 Кб на язык (требование: 20–120 Кб) |
| Тестовая коллекция | 100 документов, видимый текст ровно 2000 знаков (~1 стр. А4) |

Система запускается на одном компьютере и обслуживает клиентов локальной сети
через браузер; после однократной подготовки данных работает без интернета.

---

## Быстрый старт

```bash
cd lab2-detect
uv sync                          # либо: pip install -e .
python scripts/download_model.py # один раз: нейросетевая модель, 916 Кб
python scripts/build_corpus.py   # один раз: статьи Википедии (нужен интернет)
python scripts/make_test_docs.py # нарезка наборов из скачанных статей
python run.py
```

Дальше в браузере: «Распознавание» → кнопка «Распознать» у набора →
«Результаты»: таблица документов с активными ссылками, сводная статистика,
сравнение пар методов, графики, кнопки «Сохранить CSV/JSON/TXT» и «Печать».
Подробности — на странице «Справка» (`/help`).

Корпус, коллекция и модель лежат в репозитории (`corpus/`, `models/`), поэтому
повседневная работа интернета не требует.
