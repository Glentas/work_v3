# Лабораторная работа 9 — Система распознавания речи

**Вариант 7:** немецкий язык · предметная область «Сочинения по литературе».

Небольшое Flask-приложение (Python, зависимости — **uv**). Распознавание речи
выполняется **на сервере, офлайн, движком Vosk** — поэтому работает в
Firefox/**LibreWolf**, где браузерный Web Speech API (`SpeechRecognition`)
недоступен. Браузер лишь записывает микрофон и шлёт WAV на сервер.

## Соответствие требованиям работы
1. **Список операций, на которые система реагирует** — задан в `data/commands.json`
   и отображается в блоке «Список операций»: `help`, `read`, `stop`, `next`,
   `prev`, `first`, `list` + открытие сочинения по имени (`Faust`, `Kafka`, …).
2. **Автоматическая реакция на речевой сигнал с уведомлением** — распознанная фраза
   сопоставляется с операцией, система **сама** её исполняет и уведомляет пользователя
   (всплывающее сообщение + запись в «Журнале»).
3. **Настройки (выбор) ЕЯ** — выпадающий список языков (немецкий по умолчанию;
   английский/русский подключаются скачиванием модели).

## Быстрый старт (uv)
```bash
cd lab9-recognition
uv sync                                    # установит Flask и Vosk
uv run python scripts/download_model.py de # один раз: немецкая модель (~45 Мб)
uv run app.py                              # → http://127.0.0.1:5000
```
Откройте <http://127.0.0.1:5000>, разрешите доступ к микрофону, нажмите
**«🎙 Начать запись»**, произнесите команду (например, *«öffne Faust»*, *«weiter»*,
*«Hilfe»*), затем **«⏹ Остановить и распознать»**.

> Микрофон в браузере работает только в защищённом контексте — адрес
> `http://127.0.0.1:5000` подходит. Если микрофона нет, используйте поле
> «Симулировать» — оно проверяет сопоставление команды без записи.

Другие языки:
```bash
uv run python scripts/download_model.py en   # английский
uv run python scripts/download_model.py ru   # русский
```

## Голосовые операции (немецкий)
| Команда | Триггеры (примеры) | Действие |
| --- | --- | --- |
| `help`  | Hilfe, Befehle | показать список операций |
| `read`  | lies vor, lesen | читать текущее сочинение вслух (серверный espeak-ng) |
| `stop`  | Stopp, halt | остановить чтение |
| `next`  | weiter, nächstes | следующее сочинение |
| `prev`  | zurück, vorheriges | предыдущее сочинение |
| `first` | Anfang, erstes | к первому сочинению |
| `list`  | Liste, alle | перечислить все сочинения |
| `open`  | Faust, Kafka, Buddenbrooks, Romantik | открыть сочинение по имени |

Команда `read` озвучивает текст **серверным движком espeak-ng** (как в лабе 8),
поэтому работает в любом браузере, включая LibreWolf (нужен `sudo pacman -S espeak-ng`).
Если espeak-ng на сервере нет — приложение пробует браузерный синтез как запасной.

## Как это работает
1. `app.js` запрашивает `/api/config` (доступные языки), `/api/commands` (операции),
   `/api/essays` (тексты предметной области).
2. По кнопке записи браузер получает поток с микрофона (`getUserMedia`), накапливает
   отсчёты через **AudioWorklet** (надёжно в Firefox/LibreWolf; запасной вариант —
   `ScriptProcessor`), понижает частоту до 16 кГц и кодирует **WAV**.
3. WAV уходит в `/api/recognize?lang=…`; `recognizer.py` прогоняет его через Vosk и
   возвращает текст.
4. `commands.py` нормализует текст (регистр, пунктуация, умлауты ä→ae…), ищет
   совпадение со списком операций (подстрока + нечёткое сравнение Левенштейна ≤ 1),
   при отсутствии — ищет имя сочинения.
5. Клиент получает `{text, command}`, **автоматически исполняет** операцию и
   **уведомляет** пользователя (всплывающее сообщение + журнал).

### Зависимости
- **Vosk** — офлайн-распознавание (малая немецкая модель `vosk-model-small-de-0.15`).
- **espeak-ng** (системный пакет) — серверный синтез для команды `read`; не обязателен
  для распознавания, но нужен, чтобы «читать вслух» в LibreWolf.

### Если микрофон «то работает, то нет»
- Открывайте страницу строго по **`http://127.0.0.1:5000`** (не `localhost`/`file://`):
  микрофон доступен только в защищённом контексте.
- Приложение принудительно возобновляет `AudioContext` (`resume()`) и использует
  **AudioWorklet** — это устраняет частую в Firefox/LibreWolf проблему «пустой записи».
- В LibreWolf проверьте разрешения: значок микрофона в адресной строке → разрешить;
  при необходимости `about:config` → `media.navigator.enabled = true`.
- Следите за индикатором «уровень микрофона»: если при речи он не двигается — звук
  не захватывается (проверьте устройство ввода в настройках звука системы).
