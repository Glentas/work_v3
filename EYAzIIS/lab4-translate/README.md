# Автоматический машинный перевод текстов

Учебная система машинного перевода документов (лабораторная работа 4,
**вариант 7**): англо-русский перевод текстов предметных областей «научные
статьи по медицине» и «критика предметов изобразительного искусства».

| Параметр варианта | Значение |
|---|---|
| Направление перевода | англо-русский |
| Предметная область | научные статьи по медицине, критика предметов изобразительного искусства |
| Классы СМП | прямой (пословно-оборотный) и непрямой с трансфером |
| Анализ / грамматика | spaCy `en_core_web_sm` (функциональность лр. №3 весеннего семестра) |
| Словарь | таблица `entries` в SQLite + утилита автопополнения/корректировки |

Система запускается на одном компьютере (главный ПК) и обслуживает клиентов
локальной сети через браузер; после однократной установки модели интернета
не требует.

---

## Быстрый старт

```bash
cd lab4-translate
uv sync                          # либо: pip install -e .
python scripts/download_model.py # один раз: модель spaCy en_core_web_sm (~12 Мб)
python run.py
```

При запуске в консоль печатаются локальный и сетевой адреса:

```text
Система автоматического машинного перевода запущена.
  Локально:      http://127.0.0.1:8000
  В сети:        http://192.168.1.20:8000  <- адрес для других ПК
```

Первый старт автоматически создаёт базу `DB/translate.db` и сеет начальный
словарь (~1600 записей) из `data/seed_dictionary.tsv`.

Дальше в браузере:

1. **«Перевод»** — вставьте текст (или загрузите `.txt`, или подставьте один из
   четырёх демонстрационных текстов), выберите режим и нажмите «Перевести».
2. **«Результаты»** — перевод, статистика (слов в тексте / переведённых слов /
   покрытие / неизвестные слова), **вкладка 1** — упорядоченный по частоте
   список слов с переводами и грамматической информацией (теги частей речи и
   их расшифровка), **вкладка 2** — дерево синтаксического разбора выбранного
   предложения (SVG-граф, текстовая структура, таблица токенов). Кнопки
   «Сохранить TXT (Unicode)», «Сохранить JSON» и «Печать».
3. **«Словарь»** — просмотр, поиск и фильтры, правка/добавление/удаление
   записей, утилита автоматического пополнения (из сессии перевода или из
   нового текста), импорт/экспорт CSV.
4. **«История»** — сохранённые сессии перевода.

Подробности — на странице «Справка» (`/help`).

## Как устроен перевод

```
текст (EN) ─► анализ (spaCy) ─► трансфер (словарь + правила) ─► синтез (морфология RU)
                  │                       │                            │
        леммы, теги Penn,        выбор эквивалента по           склонение, согласование,
        роли, морфопризнаки,     части речи и ПрО, обороты,     спряжение, причастия,
        дерево зависимостей      артикли/пассив/перфект/        порядок слов именной
                                 вопрос/отрицание, падежи       и глагольной групп
```

* **Анализ** (`app/analysis.py`) — та же функциональность, что в лр. №3
  весеннего семестра: предложения, леммы, теги Penn Treebank с русской
  расшифровкой, синтаксические роли с расшифровкой, морфологические признаки
  (время, лицо, число, степень, определённость), дерево зависимостей
  (`head_id`, корень `-1`).
* **Определение ПрО** (`app/dictionary.py:detect_domain`) — подсчёт ключевых
  слов медицины/искусства; область определяет приоритет словаря при
  многозначности: *cell* → «клетка» (медицина) или «ячейка» (общая лексика).
* **Трансфер** (`app/transfer.py`) — лексическая замена (лемма → словоформа,
  приоритет: область текста → общая лексика → соседняя область; близкие
  классы частей речи) и грамматические преобразования: обороты как единое
  целое (*clinical trial* → «клиническое исследование», *in order to* →
  «чтобы»); опускание артиклей; пассив (*was examined* → «был осмотрен»,
  *is caused* → «вызывается»); перфект (*has developed* → «развил»,
  с *for/since* — несовершенный вид); прогрессив (*was developing* →
  «развивал»); модальность (*must/should* → «должен» + инфинитив, *can* →
  «может», *will* → будущее); вопрос (*Does …?* → «… ли ?», wh-вопросы
  сохраняют порядок); отрицание; посессив (*the doctor's decision* →
  «решение врача»); of-конструкция (*the color of the painting* → «цвет
  картины»); составные существительные (*blood test* → «анализ крови»);
  управление предлогов с учётом контекста (*in the hospital* — место /
  *put in the box* — направление; *by doctors* — творительный; *by 30
  percent* — «на 30 процентов»; *depend on* — «от»; *for centuries* —
  «веками»); квантификаторы и числительные с падежным управлением
  (*many symptoms* → «много симптомов», *two weeks* → «две недели»).
* **Синтез** (`app/morphology.py`) — продуктивные правила русского
  словоизменения + таблицы исключений + явные формы в словаре (приоритет):
  6 падежей × 2 числа × 3 рода с одушевлённостью; согласование
  прилагательных, местоимений и причастий; спряжение (настоящее/простое
  будущее, прошедшее по роду подлежащего, возвратность); краткие и полные
  страдательные причастия; деепричастия; степени сравнения.
* **Режим прямого перевода** — только лексическая замена элементов и
  оборотов словарными эквивалентами без морфологического синтеза;
  результат близок к пословному (как описано в ТЗ для систем первого
  поколения).

Неизвестные слова помечаются в переводе `[скобками]`, учитываются в
статистике и одним нажатием заносятся утилитой пополнения в словарь
(часть речи — из разбора, предложение перевода — практическая
транслитерация: *therapy* → «терапия») с пометкой «требует
проверки».

## Формат грамматической информации словаря

Поле `gram` (TSV/CSV/форма правки): `m|f|n` — род; `anim` — одушевлённость;
`inv` — неизменяемость; `adjdecl` — склоняется как прилагательное (учёный);
`impf|pf` — вид; `pair:` — парный вид; `pp:` — краткое причастие;
`pl:`/`gpl:` — формы множественного числа; `gov:` — падеж дополнения;
`govprep:` — предлог дополнения (влиять → `gov:acc,govprep:на`);
`comp:`/`compattr:`/`sup:` — степени сравнения; `forms:` — явные словоформы
(`forms:nompl=люди;genpl=людей`). Явные формы всегда важнее правил.

## Тесты

```bash
python -m pytest           # 63 проверки
```

Морфология и словарь тестируются без модели; тесты трансфера и веб-потока
пропускаются, если `en_core_web_sm` не установлена (как нейросетевые тесты
в лр. №2).

## Ограничения учебной системы

Словарный перевод (вне словаря — `[слово]`); обороты переводятся словарной
формой (знаменательные склоняются по падежу корня оборота); вид глагола
выбирается по словарной паре; артикли не переводятся; запятые при
придаточных не расставляются; конструкции *make/consider X Y* и эллипсисы
передаются упрощённо. Пути улучшения — в разделе 6 справки (`/help`).
