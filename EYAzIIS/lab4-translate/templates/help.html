Справка

{{ app_title }} · {{ app_variant }}. Учебная система машинного перевода (МП) документов для локальной сети; после однократной установки модели работает без интернета.

1. Назначение и класс системы

Система реализует два класса СМП из теоретической части работы:

  • Прямой (пословно-оборотный) перевод — элементы входного текста заменяются переводными эквивалентами из словаря; учитывается локальный контекст — обороты (многословные статьи словаря) заменяются как единое целое. Переводная модель кроме лексических соответствий не используется.
  • Непрямой перевод с трансфером — после этапа анализа (синтаксическая структура предложения) выполняется этап межъязыковых операций (трансфер): грамматические преобразования и перестановки, — затем синтез предложения выходного языка с порождением русских словоформ. Анализ ведётся в категориях входного языка, синтез — в категориях выходного.

Компонент знаний о предметной области (ПрО): система определяет область текста (медицина / критика изобразительного искусства) по ключевым словам и использует её при разрешении лексической многозначности (cell → «клетка» в медицинском тексте и «ячейка» в общем). Словарь разделён на три части: общая лексика, медицина, искусство.

2. Как выполнять перевод

  1. Страница «Перевод»: вставьте текст или загрузите файл .txt (кодировки UTF-8, UTF-8 with BOM, Windows-1251).
  2. Выберите режим (с трансфером / прямой) и нажмите «Перевести».
  3. Страница результатов: перевод, статистика (количество слов во входном тексте, количество переведённых слов, покрытие, неизвестные слова, время), вкладка 1 — упорядоченный по частоте встречаемости список слов с переводами и грамматической информацией, вкладка 2 — дерево синтаксического разбора выбранного предложения (графика, текстовая структура и таблица токенов).
  4. Кнопки «Сохранить TXT (Unicode)» и «Печать» — сохранение и распечатка результатов перевода и частотного списка (файл .txt в кодировке UTF-8 с BOM, открывается «Блокнотом» Windows).

3. Этапы обработки текста

ЭтапМодульЧто делает
Анализapp/analysis.py spaCy en_core_web_sm (функциональность лр. №3 весеннего семестра): деление на предложения, лемматизация, теги частей речи Penn Treebank, синтаксические роли, морфологические признаки (время, лицо, число, степень, определённость).
Определение ПрОapp/dictionary.py Подсчёт ключевых слов медицины и искусства — приоритетная область словаря.
Трансферapp/transfer.py Поиск эквивалентов (лемма → словоформа, приоритет области); обороты как единое целое; грамматические преобразования: артикли опускаются, пассив (was examined → «был осмотрен»), перфект (has developed → «развил»), прогрессив (was developing → «развивал»), модальность (must → «должен» + инфинитив), вопрос (Does … ? → «… ли ?»), отрицание, посессив (the doctor's decision → «решение врача»), of-конструкция (the color of the painting → «цвет картины»), составные существительные (blood test → «анализ крови»), падежное управление предлогов и глаголов, направление/место (in the hospital / put in the box).
Синтезapp/morphology.py Порождение русских словоформ: склонение существительных (6 падежей × 2 числа, 3 рода, одушевлённость), согласование прилагательных/местоимений/причастий, спряжение глаголов (настоящее, прошедшее, будущее, возвратность), краткие страдательные причастия, деепричастия, числительные с управлением («два пациента», «пять пациентов»). Таблицы исключений + явные формы в словаре имеют приоритет над правилами.
Статистикаapp/translator.py Количество слов, переведённых слов, чисел, артиклей, неизвестных слов; покрытие; частотный список (лемма, словоформы, часть речи, тег + расшифровка, роль + расшифровка, перевод) — функциональность лр. №1 весеннего семестра.

4. Словарь и утилита пополнения/корректировки

  • Словарь хранится в таблице entries базы SQLite (DB/translate.db): источник (лемма или оборот), часть речи, перевод, грамматическая информация (JSON), предметная область, статус проверки.
  • Автоматическое пополнение: страница «Словарь» → утилита пополнения — из сохранённой сессии перевода или из нового текста; неизвестные слова заносятся с определённой при разборе частью речи и предложенным переводом (транслитерация для терминов и имён собственных), помечаются «требует проверки».
  • Корректировка: правка записей в таблице, добавление, удаление, подтверждение; массовая корректировка — экспорт/импорт CSV (разделитель «;», кодировка Unicode).
  • Формат поля «Грамматика»: m/f/n — род; anim — одушевлённость; inv — неизменяемость; impf/pf — вид глагола; pair:осмотреть — парный вид; pp:осмотрен — краткое причастие; pl:/gpl: — формы мн. ч.; gov:dat — управление; govprep:на — предлог дополнения; comp:/compattr:/sup: — степени сравнения; forms:pastm=шёл;… — явные словоформы.
  • Посев начального словаря: python scripts/seed_dictionary.py (данные — data/seed_dictionary.tsv, выполняется автоматически при первом запуске).

6. Ограничения учебной системы и пути улучшения

  • Словарный перевод: слова вне словаря помечаются [слово] (пополняйте словарь утилитой).
  • Обороты переводятся словарной формой без склонения по месту (кроме падежа/числа знаменательных оборотов).
  • Вид глагола (совершенный/несовершенный) выбирается по словарной паре, а не по семантике контекста; артикли не переводятся; запятые при придаточных не расставляются автоматически.
  • Конструкции make/consider X Y, инверсии и эллипсисы передаются упрощённо.
  • Пути улучшения: статистическая/нейронная модель ранжирования вариантов перевода, расширение правил порядка слов, морфологический анализатор русского языка (pymorphy2) вместо правил, обучение на параллельных корпусах предметных областей, расстановка пунктуации по дереву зависимостей.

7. Запуск системы

cd lab4-translate
uv sync                          # либо: pip install -e .
python scripts/download_model.py # один раз: модель en_core_web_sm (~12 Мб)
python run.py                    # сервер на порту 8000, доступен из локальной сети

При старте в консоль печатаются локальный и сетевой адреса. Первый запуск автоматически создаёт базу DB/translate.db и сеет начальный словарь (~1600 записей).
