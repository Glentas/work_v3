Справка (help)

1. Назначение системы

Система автоматически строит реферат текстового документа на французском или английском языке из предметных областей «научные статьи по computer science» и «сочинения по литературе» (вариант 7). Реферат состоит из двух разделов:

  • классический реферат — набор наиболее информативных предложений исходного текста (метод sentence extraction);
  • реферат в виде списка ключевых слов — иерархический список наиболее информативных слов и словосочетаний (именных групп).

2. Порядок работы

  1. На главной странице выберите источник текста:
    • Из коллекции — готовый документ тестовой коллекции (8 документов одинакового размера ~10 страниц А4, 2 языка × 2 области);
    • Загрузить файл — свой текстовый файл .txt (UTF-8);
    • Вставить текст — текст, вставленный в поле ввода.
  2. При необходимости укажите язык (или оставьте автоопределение), предметную область и размер реферата (по умолчанию 10 предложений — рекомендация методики).
  3. Нажмите «Построить реферат». Откроется страница результата.
  4. На странице результата доступны:
    • активная ссылка на исходный документ (локальная копия и оригинальный источник);
    • сохранение в файл (.txt или .html);
    • печать результата (кнопка «Печать»);
    • детализация весов предложений (служебная строка под каждым предложением реферата).

3. Метод построения реферата

Шаг 1. Веса слов. Учитываются только значимые слова: стоп-слова, числа и слова чужой письменности отбрасываются. Базовый вес слова — TF·IDF: w(t) = tf(t,D)·log(|DB|/df(t)).

Шаг 2. Веса предложений. Вес предложения — произведение трёх функций:

  • Posd(Sᵢ) = 1 − BD(Sᵢ)/|D| — положение предложения в документе (BD — число символов до Sᵢ, |D| — число символов в документе);
  • Posp(Sᵢ) = 1 − BP(Sᵢ)/|P| — положение предложения в абзаце;
  • Score(Sᵢ) = Σt∈Sᵢ tf(t,Sᵢ)·w(t,D) — модифицированный TF-IDF, где w(t,D) = 0.5·(1 + tf(t,D)/tfmax(D))·log(|DB|/df(t)).

Итоговый вес: W(Sᵢ) = Posd(Sᵢ)·Posp(Sᵢ)·Score(Sᵢ).

Шаг 3. Генерация. Выбираются N предложений с наибольшим весом в порядке их следования в тексте (рекомендуется N = 10).

Нейросетевой метод (замена технологии OSTIS). Многоязычная нейросеть-трансформер (либо резервная нейросеть skip-gram) строит семантические векторы предложений и применяется для: (а) защиты отбора от семантических повторов (принцип максимальной предельной значимости MMR: λ·значимость − (1−λ)·избыточность); (б) группировки синонимичных ключевых слов в иерархическом списке; (в) оценки близости реферата документу.

4. Частые вопросы

  • Почему реферат «тяготеет» к началу текста? Позиционные функции Posd и Posp методики повышают вес предложений из начала документа и абзаца — это ожидаемое поведение метода.
  • Что означает «≈» в списке ключевых слов? Термин не содержит корень, но семантически близок ему по нейросетевым эмбеддингам.
  • Какой язык поддерживается? Французский и английский (языки варианта 7); автоопределение работает по служебным словам.
  • Можно ли обработать свой файл? Да, вкладка «Загрузить файл» (текст .txt в кодировке UTF-8).
  • Как отключить нейросеть? Снимите флажок «нейросетевое уточнение отбора» — будет применён чистый sentence extraction по формулам методики.
