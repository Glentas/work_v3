# Лабораторная работа «Автоматическое реферирование документов» — вариант 7

Языки: **французский, английский** · Методика: **sentence extraction +
нейросетевой метод** (вместо технологии OSTIS) · Области: **научные статьи по
computer science, сочинения по литературе**.

Веб-система на **FastAPI**: на входе — текстовые документы одинакового
размера (~10 стр. А4), на выходе — активная ссылка на исходный документ и
реферат из двух разделов (классический + иерархический список ключевых слов),
сохранение в файл (.txt/.html) и печать, простой интерфейс со справкой.
Переключение вкладок «Из коллекции / Загрузить файл / Вставить текст»
работает без JavaScript (чистый CSS `:checked`), поэтому форма корректна
даже при отключённых/заблокированных скриптах в браузере.

## Быстрый старт

Управление зависимостями и виртуальным окружением — через
[uv](https://docs.astral.sh/uv/) (установка самого uv: `pip install uv`
или `curl -LsSf https://astral.sh/uv/install.sh | sh`). Версия Python
зафиксирована в `.python-version`, зависимости и блокировки — в
`pyproject.toml` и `uv.lock`.

```bash
uv sync                     # создать .venv и установить зависимости (включая dev-группу)
uv run python run.py        # запуск сервера: http://127.0.0.1:8000
```

Эквивалентно можно запустить `uv run uvicorn app.main:app --port 8000`.

При первом запуске нейросетевой бэкенд скачает квантованную многоязычную
модель `paraphrase-multilingual-MiniLM-L12-v2` (ONNX int8, ~112 МБ) в каталог
`.cache/` — нужен доступ в интернет. Без интернета система автоматически
переключится на резервную нейросеть **skip-gram (numpy)**, обучаемую на
коллекции, либо на чистый sentence extraction (флажок в интерфейсе).

### Управление зависимостями (uv)

```bash
uv add <пакет>              # добавить зависимость в pyproject.toml + обновить uv.lock
uv remove <пакет>           # удалить зависимость
uv lock                     # пересоздать файл блокировки uv.lock
uv sync                     # привести .venv в соответствие с блокировкой
uv sync --no-dev            # без dev-группы (matplotlib, python-docx, httpx)
uv sync --extra torch       # + опциональный бэкенд sentence-transformers (torch)
uv run python scripts/run_evaluation.py   # любой скрипт в окружении проекта
uv python list              # доступные интерпретаторы
```

Выбор нейросетевого бэкенда: `NEURAL_BACKEND=auto|onnx|transformers|skipgram|none`
(для `transformers` сначала выполните `uv sync --extra torch`).

## Маршруты

| Маршрут | Назначение |
|---|---|
| `GET /` | главная: выбор документа коллекции / загрузка файла / вставка текста, параметры |
| `POST /summarize` | обработка → редирект на результат |
| `GET /result/{id}` | реферат: 2 раздела, активные ссылки на источник, сохранение, печать |
| `GET /result/{id}/download?fmt=txt\|html` | сохранение в файл |
| `GET /document/{id}` | просмотр исходного документа (активная ссылка) |
| `GET /help` | справочная система |
| `GET /api/collection`, `GET /api/summarize/{id}` | JSON API |

## Метод (строго по методичке + нейросеть вместо OSTIS)

1. Веса слов: TF·IDF; стоп-слова, числа и слова чужой письменности не учитываются.
2. Вес предложения: `W(Si) = Posd(Si)·Posp(Si)·Score(Si)`, где
   `Posd = 1 − BD(Si)/|D|`, `Posp = 1 − BP(Si)/|P|`,
   `Score(Si) = Σ tf(t,Si)·w(t,D)`,
   `w(t,D) = 0.5·(1 + tf(t,D)/tf_max(D))·log(|DB|/df(t))`.
3. Генерация: N=10 предложений с наибольшим весом в порядке следования в тексте.
4. Нейросетевой метод: эмбеддинги предложений (многоязычный трансформер,
   int8-ONNX; резервно skip-gram) → MMR-отбор без семантических повторов,
   группировка ключевых слов, оценка адекватности реферата.

## Тестирование и отчёт

```bash
uv run python scripts/run_evaluation.py   # метрики по 8 документам × 2 режима
uv run python scripts/make_diagram.py     # схемы алгоритма и структуры
uv run python scripts/make_report.py      # docx-отчёт со всеми разделами методички
```

Средние результаты (бэкенд transformers-onnx): ROUGE-1 ≈ 0.35, покрытие
ключевых терминов ≈ 0.69, семантическая адекватность ≈ 0.90, время ≈ 30 мс
(чистый extraction) / ≈ 1.8 с (с нейросетью); нейросетевой MMR снижает
семантическую избыточность реферата с 0.42 до 0.38.
